### 🌈 ESP32 RGB LED Controller
### 🚀 Project Overview
- OLED show 2 options to start program
- Design sliders on Blynk app 
- Using Blynk to control brightness of 3 basic colors (Red, Green, Blue) to display billions of colors.

| Blue     | GPIO 13    |

| Button 2 | GPIO 19    |
